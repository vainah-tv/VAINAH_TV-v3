Russia 1HD / Vaynah TV / Radio player for Windows 10/11 x64

1. Extract the ZIP into an ordinary folder.
2. Run Build.cmd. It compiles Russia1.exe and immediately starts Russia 1HD.
   Compiler output is saved in build.log.
3. Later, use Run.cmd or Russia1.exe to watch without rebuilding.

The build requires Visual Studio Build Tools with "Desktop development with C++"
and Windows SDK. The built EXE runs without Visual Studio, VLC, or a browser.

This stream has not been tested in Windows here. If compilation fails, send
build.log. If playback fails, send the error displayed by the player.

Controls: double-click the picture for fullscreen or to leave it; Esc also
leaves fullscreen. Double-clicking controls does not change the window mode.
Choose РОССИЯ 1HD, ВАЙНАХ ТВ, or РАДИО ГРОЗНЫЙ in the left sidebar. The first channel
keeps the direct 1080p address. The other channels use the supplied stream
addresses. When РАДИО ГРОЗНЫЙ is selected, the supplied radio_gr.png artwork appears
in the viewing area and remains visible in fullscreen. It is embedded in the
EXE, so the PNG file is not needed after building. There is no quality selector.
Use the speaker icon to mute. Stream addresses may change or expire.
Fullscreen fills the entire screen and
hides the lower control bar. Double-click the picture or press Esc to return.
Video may be stretched on displays with a different aspect ratio.

Adjust sound with the volume slider next to the speaker. The mouse wheel
changes volume by 5 percent per step anywhere over the player, including
the video in fullscreen. A temporary volume indicator appears above the video.
Moving the slider or wheel unmutes the sound.

The supplied Russia 1 / Vaynah artwork is embedded as the EXE and window icon.
Windows shortcuts to Russia1.exe use this icon as well.

The red pushpin from the supplied image is embedded in the EXE. It sits at the
right end of the controls and toggles "always on top". Hover over it for the tooltip
"Поверх всех окон". The Windows title bar uses the same dark color as the app
where the operating system supports colored title bars.

Programme guide: click the EPG button next to the pushpin. A translucent panel
opens over the picture and loads current Russia 1HD listings from epg.iptvx.one,
showing Moscow time. Click EPG again or the X on the panel to hide it. Internet
access is required. If today's schedule cannot be found, an error is shown.
Verified listings for Vaynah TV and Radio Grozny are not available; the guide
says so when those channels are selected. Playback continues while it is open.
