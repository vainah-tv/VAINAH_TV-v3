# Россия 1 / Вайнах — Android

Android-приложение для трёх потоков из исходной Windows-версии: Россия 1HD, Вайнах ТВ и Радио Грозный. Видео и звук воспроизводятся через Media3 HLS. Для радио показывается исходная обложка. Есть регулировка и отключение звука, полноэкранный режим (кнопка или двойное касание), программа передач Россия 1HD через `epg.iptvx.one`. Для двух других каналов проверенной программы нет.

## Собрать APK на GitHub

1. Создайте пустой репозиторий GitHub. Загрузите **содержимое этой папки** в корень репозитория, включая скрытую папку `.github/workflows` (для неё удобнее загрузка через Git или GitHub Desktop).
2. Откройте **Actions → Android APK**. После `push` сборка запускается сама; также можно выбрать **Run workflow**.
3. В успешном запуске в разделе **Artifacts** скачайте `Russia1Player-debug-apk`. Внутри будет `app-debug.apk`.

Сборка использует JDK 17, Gradle 9.4.1, Android Gradle Plugin 9.2.1, compile/target SDK 37 (Android 17), min SDK 23. Локально: установите JDK 17, Android SDK Platform 37 и Gradle 9.4.1, затем выполните `gradle :app:assembleDebug` в этой папке. Android Studio также может импортировать проект через `settings.gradle`.

Это отладочный APK для установки вручную. Для публикации в Google Play нужен подписанный release AAB с вашим ключом; ключ не следует загружать в GitHub. Не меняйте `applicationId` после публикации обновлений. Ссылки трансляций предоставлены исходным проектом и могут устареть либо быть географически недоступны. Работоспособность потоков и EPG проверяется на устройстве с доступом в интернет.

Windows-исходники (`player.cpp`, `Build.cmd`, изображения и `README.txt`) сохранены для справки и сборки прежнего EXE. Функция «поверх всех окон» из Windows-версии не перенесена: Android-приложение работает как обычный плеер на экране. При уходе с экрана воспроизведение приостанавливается.
